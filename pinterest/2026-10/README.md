# Pinterest — October 2026

This folder is prepared for the QuickAgeCalc October 2026 Pinterest campaign.

## Upload order

1. Upload the 62 PNG files from `quickagecalc_pinterest_october_2026_images.zip` into this folder.
2. Keep every filename exactly as supplied.
3. Confirm the files are visible on the `main` branch.
4. Upload `quickagecalc_pinterest_bulk_october_2026.csv` in Pinterest Business → Settings → Import content → Upload .csv.

The Pinterest CSV uses public raw GitHub URLs in this format:

`https://raw.githubusercontent.com/officecomenzi-hub/quickagecalc/main/pinterest/2026-10/FILENAME.png`

## Campaign structure

- 62 Pins total
- 2 Pins per day from October 1–31, 2026
- Priority: Cat Age Calculator launch and pet-age content
- Supporting topics: exact age, days/weeks/months/hours, generations, birth years, birthdays, pregnancy, date difference, retirement
- Image size: 1000 × 1500 px (2:3)
- Scheduling: Europe/Bucharest publishing windows converted to UTC in the Pinterest CSV
- October 25 daylight-saving change is already accounted for

Do not rename the image files after uploading them, because the bulk CSV Media URL values depend on the exact filenames.
